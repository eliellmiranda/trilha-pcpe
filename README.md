# Trilha do edital PCPE — Agente de Polícia Civil

Página estática responsiva com checklist e percentuais de conclusão por matéria e no geral.

## Publicar gratuitamente no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `trilha-pcpe`.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`, depois salve.
5. Abra a URL publicada pelo GitHub Pages.

## Como funciona a porcentagem
- Cada tópico final com checkbox tem peso igual no cálculo geral: `100 ÷ total de tópicos`.
- Em cada matéria, o peso é `100 ÷ tópicos daquela matéria`.
- Títulos de agrupamento ajudam a organizar e podem marcar todos os itens de uma vez, mas não contam separadamente.
- O progresso é salvo no armazenamento local do navegador. Ele não sincroniza automaticamente entre dispositivos ou navegadores.
- Use **Baixar backup** e **Restaurar backup** para transportar suas marcações em um arquivo JSON.

A árvore foi montada a partir do texto de edital fornecido. Confira a legislação e as atualizações oficiais antes da prova.
